What's inside

Built for real users

Smart Timer Engine

A finite state machine that persists across crashes. Survives restarts, dynamically adjusts when you change settings — never resets your progress.

Full-Screen Break Overlay

A separate window that appears over everything when a break is due. Optional Strict Mode prevents skipping.

Eye Health Dashboard

Daily stats, compliance rate, streak tracking, and beautiful weekly bar charts (Recharts). Know your habits at a glance.

Google Auth + Guest Mode

Sign in with Google for cloud sync, or use the app entirely offline as a guest. Row-Level Security keeps your data private.

Silent Auto-Updates

Checks for updates in the background, downloads silently, and shows a live progress toast. Install on quit — just like professional software.

System Tray Integration

Lives quietly in your tray. Closing the window hides it — the timer keeps running. Quit only when you truly want to.
